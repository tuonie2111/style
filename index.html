Basic Media Queries

In this assignment you will add two media queries to the css file.

  • The first media query should trigger at 772px and change the layout of the divs to be 45% of the viewport width.
  • The second media query should trigger at 998px and change the layout of the divs to be 30% of the viewport width.

You will need to make additional changes to ensure that the divs appear next to each other.
